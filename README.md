# ReadEaseGeo

HTML games with eye tracking functionality using WebGazer.js

This project is built on top of [WebGazer.js](https://github.com/brownhci/WebGazer) 
by the Brown WebGazer Team.

## What I added:
- HTML/CSS/JS files for games 
- Minor modifications to main.js for game integration
- "ourHelper" folder within the webgazer directory

## Project Structure:
- My game files are in the root directory
- I only added the "ourHelper" folder inside the existing webgazer folder
- All other modifications are minimal additions to existing files
